Real-Time Character Counter

A simple and responsive message box with a real-time character counter. Users can type a message, view the number of characters entered, and see the remaining character limit.

Features
Responsive design for desktop, tablet, and mobile
Textarea with a 200-character limit
Real-time character counting
Displays remaining characters
Warning message when the character limit is reached
Custom focus effect with a green glow
Clean and modern UI
Font Awesome icon integration
Technologies Used
HTML5
CSS3
Tailwind CSS
JavaScript
Font Awesome
How It Works

The character counter listens for the input event on the textarea.

For example:

110/200 characters
90 characters remaining

Once the user reaches 200 characters, further typing is prevented and a warning message is displayed.
